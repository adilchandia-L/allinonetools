How to use

Pick from list: type one name or option on each line, then tap Pick one. Tick "Remove winner" to take each winner out, so you can pick several different people. Flip coin and Roll dice work with a tap.

Is the choice fair?

It uses your device's random number generator, so every name has the same chance each time.

Can I pick more than one winner?

Yes. Tick Remove winner after each pick, then pick again. The list gets shorter each time.

Does it save my list?

No. The list and picks are kept only while the page is open.
