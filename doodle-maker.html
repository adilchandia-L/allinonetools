How to use

Type anything you want drawn, pick a style, and tap Draw it. Use Another version for a new take, or Save to download an SVG file.

FAQ

Why does it say to open in claude.ai?

This tool uses Claude to draw, so it works only inside claude.ai.

Why is the drawing not what I wanted?

Try simpler wording and be specific, like 'a red cat sitting on a box'.

What file do I get?

An SVG file, which opens in most browsers and design apps.
