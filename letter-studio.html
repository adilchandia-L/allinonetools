How to use

Pick an occasion, then a look. Type who the letter is to and from, choose a tone, and tap Write my letter. Edit the text in the box, add stickers, change the font or color, and use Print or Save to finish.

FAQ

Can I change the wording?

Yes. Edit any line in the box. The preview updates as you type.

How do I add emojis?

Tap a sticker in the bar to insert it where the cursor is, or use Add emojis to every line.

How do I keep my letter?

Use Save as text, Copy, or Print or save as PDF.

Why do the letters look similar?

They are fixed templates, so the same occasion and tone give similar wording. Edit the text to make it personal.
