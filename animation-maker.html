FAQ

Why does it say to open in claude.ai?

This tool uses Claude to make animations, so it works only inside claude.ai.

Can I get an MP4 video?

No, the output is an animated SVG that plays in a browser. Use Frame Studio for video export.

Why is it slow?

Making an animation takes a little while. Wait for the message to finish.
